# Samuk SAC

**Samuk SAC** se especializa en la distribución y venta de tuberías y accesorios para diversas aplicaciones. Ofrece productos de PVC, HDPE, acero y otros materiales, además de conexiones, válvulas y juntas. La empresa brinda asesoría técnica, soporte en la selección de productos y asistencia en instalación y mantenimiento. Con un fuerte compromiso con la calidad y el servicio postventa, Samuk SAC garantiza soluciones efectivas y duraderas, adaptándose a las necesidades de cada proyecto.

## Requisitos Previos

Para ejecutar este proyecto localmente, asegúrate de tener instalados los siguientes componentes:
- **Git** para clonar el repositorio, crear ramas y actualizar el proyecto. Puedes [descargarlo aquí](https://git-scm.com/).
- **Visual Studio Code (VS Code)** como editor de código. Puedes [descargarlo aquí](https://code.visualstudio.com/).
- **PHP** (versión recomendada: 7.4 o superior).
- **Servidor local** como **XAMPP** o **WAMP**.
- **MySQL** para la base de datos.
